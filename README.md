# Горы мира — демо на OpenGlobus

Мгновенное переключение между известными горами, маршруты восхождения на рельефе, облёт вокруг вершины.
Движок — [OpenGlobus](https://github.com/openglobus/openglobus) (Михаил Гевлич), версия 0.28.7, грузится с CDN jsDelivr.
На телефоне 0.28.7 подгружает плитки заметно спокойнее, чем 1.0.0-rc30, поэтому основная версия — на ней.
Для сравнения: `rc30/` — та же страница на 1.0.0-rc30 (Bing, Mapterhorn, depthOffset), `old/` — исходная версия до переноса функций.

Сайт: https://fox-creator2.github.io/mountains-demo/

Как устроено:
- снимки Esri (или Bing — переключатель в ⚙): глобальная подложка только с грубыми тайлами (до 5-го зума) — «вид с орбиты»,
  у каждой горы свой слой с `extent`: внутри рамки детальные тайлы, снаружи ничего не грузится;
- рельеф `GlobusRgbTerrain`;
- камера задаётся курсом, наклоном и расстоянием относительно вершины; ориентация — `camera.set(глаз, вершина, нормаль)`,
  поэтому боковой вектор камеры всегда перпендикулярен нормали к поверхности (горизонт без крена);
- облёт меняет курс, наклон и расстояние — ползунки в панели «Камера»;
- солнце (☀): освещение по настоящему положению солнца для выбранных даты и местного солнечного времени, проигрывание суток;
- маршруты (до 4 на гору) — слой `Vector`, линия на 12 м над рельефом; точки подгоняются по известной высоте вдоль маршрута,
  линии ложатся на рельеф, провалы обходятся, канатная дорога — пролёт с провисанием;
- подписи точек стоят над окружающим рельефом, поднимаются, если их закрывает склон, и прячутся при наложении на экране
  (остаётся важнейшая: вершина, затем более высокие точки).

Точки маршрутов — схема по известным хижинам и лагерям, а не GPS-треки: точность — порядка сотен метров.
