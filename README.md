# Горы мира — демо на OpenGlobus

Мгновенное переключение между известными горами, пролёт и облёт вокруг вершины.
Движок — [OpenGlobus](https://github.com/openglobus/openglobus) (Михаил Гевлич), версия 0.28.7, грузится с CDN jsDelivr.

Как устроено:
- глобальная подложка грузит только грубые снимки (до 5-го зума) — «вид с орбиты»;
- у каждой горы свой слой снимков с `extent`-рамкой: внутри неё детальные тайлы, снаружи ничего не грузится;
- камера ставится через `planet.viewLonLat` (телепорт) или `planet.flyLonLat` (пролёт);
- облёт — `camera.rotateAround` вокруг вертикали через вершину.

Сайт: https://fox-creator2.github.io/mountains-demo/
